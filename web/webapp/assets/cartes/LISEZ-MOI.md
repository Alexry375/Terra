# Les visuels des cartes ne sont pas dans ce dépôt

Ce dossier est vide, et c'est voulu : les illustrations des cartes de
*Terraforming Mars : Ares Expedition* appartiennent à leur éditeur. Ce projet ne
les distribue pas.

**Si vous possédez le jeu**, numérisez vos cartes et déposez ici un fichier par
carte. Les noms attendus sont donnés par `../manifeste.json`, champ `image` :

```json
{ "nom": "Adaptation Technology", "image": "cartes/adaptation-technology.webp" }
```

Le format n'a pas d'importance tant que le navigateur sait le lire, mais le nom
de fichier doit être exactement celui du manifeste.

**Sans ces fichiers, le programme fonctionne quand même** : chaque carte porte
son nom en clair sous son emplacement.
